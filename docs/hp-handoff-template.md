# HP掲載依頼テンプレート

個人サイト「Build Log」(`C:\Core\HP`)にこのプロジェクトを掲載/更新したい。
以下をこのプロジェクトのフォルダに `docs/引き継ぎ.md` として書いてほしい
(無ければ `docs/` を作ってOK)。**HP側のファイルは直接編集しないでください。**
反映は別セッションが行います。

## 書いてほしい内容

1. **一覧カード用の一言**(30〜40字程度、体言止め寄り)
   何のためのアプリで、一番の売りは何か。

2. **詳細ページ用の説明**(数段落)
   - 何を解決するか / 何ができるか
   - 実測値や検証済みの事実があれば数値そのまま(丸めない)
   - 現状の制限・未検証の部分があれば正直に(このサイトは誇張しない方針)
   - スタック(使用言語・主要ライブラリ)

3. **スクリーンショット**(あれば)
   - 個人情報(パス・実写真・実カメラ映像・氏名など)が写っていないことを確認済みのものを
     `docs/images/` などに置く
   - 実データが使えない場合は「公開用のデモ状態で再現した図」と明記してもらえればOK

4. **公開状況**
   - 配布中か、審査中か、まだ非公開か
   - ダウンロード・購入リンクを載せていいか

## 守ってほしいこと

- **HPのファイル(`styles.css` / `script.js` / `index.html` / 他のproject-*.html)は触らない。**
  内容の引き継ぎだけ。反映(実装・デザイン統一・pushまで)はBuild Log側で行う
- 数値は実測のまま、環境条件(CPU/OSなど)も削らない
- 個人が特定できる情報(本名・住所・実写真・実際のIP等)は書かない/写さない

書き終わったら、このファイルのパスだけ教えてください。
