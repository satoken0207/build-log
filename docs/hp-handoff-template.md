# HP掲載依頼テンプレート

個人サイト「Build Log」(`C:\Core\HP`)にこのプロジェクトを掲載/更新したい。

**書く場所**: `C:\Core\HP` の中ではなく、**今あなたが作業しているこのプロジェクトの
ルートフォルダ直下**に `docs\引き継ぎ.md` として書いてください
(`docs` フォルダが無ければ新規に作ってOK)。

例: 作業フォルダが `C:\Core\ほにゃらら` なら → `C:\Core\ほにゃらら\docs\引き継ぎ.md`

**HP側のファイル(`C:\Core\HP` 以下)は直接編集しないでください。** 内容の引き継ぎだけで、
反映(実装・デザイン統一・push)は別セッション(Build Log側)が行います。

## 書いてほしい内容

1. **一覧カード用の一言**(30〜40字程度、体言止め寄り)
   何のためのアプリで、一番の売りは何か。

2. **詳細ページ用の説明**(数段落)
   - 何を解決するか / 何ができるか
   - 実測値や検証済みの事実があれば数値そのまま(丸めない)
   - 現状の制限・未検証の部分があれば正直に(このサイトは誇張しない方針)
   - スタック(使用言語・主要ライブラリ)

3. **スクリーンショット**(あれば)
   - 個人情報(パス・実写真・実カメラ映像・氏名など)が写っていないことを確認済みのものを
     `docs/images/` などに置く
   - 実データが使えない場合は「公開用のデモ状態で再現した図」と明記してもらえればOK

4. **公開状況**
   - 配布中か、審査中か、まだ非公開か
   - ダウンロード・購入リンクを載せていいか

## 守ってほしいこと

- 数値は実測のまま、環境条件(CPU/OSなど)も削らない
- 個人が特定できる情報(本名・住所・実写真・実際のIP等)は書かない/写さない

書き終わったら、このファイルのパスだけ教えてください。
